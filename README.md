# Hotel Reservation System

A Java-based console application for managing hotel room reservations.

## Features
- View available rooms
- Search rooms by category
- Book rooms
- Cancel reservations
- Manage reservation details
- Simulate payment
- Store reservation details using file handling

## Room Categories
- Single Room
- Double Room
- Deluxe Room
- Suite Room

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Console-based application
